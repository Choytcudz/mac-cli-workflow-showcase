# Security policy

Do not submit credentials, private keys, tokens, personal data, production logs,
or live system configuration in an issue or pull request.

For a suspected vulnerability, use GitHub's private vulnerability reporting or
Security Advisory feature rather than a public issue. Include a minimal,
sanitized reproduction and avoid destructive testing.

This repository contains public examples only. Findings involving a private
deployment should be reported without exposing that deployment's identifiers,
addresses, credentials, or logs.
